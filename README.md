# Sparkcurv HR Portal

HR portal for Sparkcurv: attendance (Login/Logout, 8-hour day), leave, WFH and permission requests,
payroll and payslips, change requests, holidays, company policies, access control and a credential vault.

- **Backend:** FastAPI + MySQL/MariaDB (`backend/`, entry point `server.py`, code in `backend/app/`)
- **Frontend:** React + Tailwind + shadcn/ui (`frontend/`)

See [INSTALLATION.md](INSTALLATION.md) for setup and deployment.
